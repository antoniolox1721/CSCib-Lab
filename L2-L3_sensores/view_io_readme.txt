
CSC Simulink Demo
-----------------

You can acquire some signals of the flexbar
(please do not start without the indication of the professor):

>> view_record_pci6221.mdl
	or
>> view_record_mio16e4.mdl

Note: the mdl file to use is different for each workbench


To see the acquired signals:
>> view_io

To save the acquired signals:
>> view_io save
